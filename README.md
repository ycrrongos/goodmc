# GoodMC

GoodMC - GoodMC 玩法增强

基于 PaperMC 的 Minecraft 服务器插件，适用于 Minecraft 1.21+。

## 功能

- GoodMC 玩法增强

## 安装

1. 下载最新 Release 中的 `.jar` 文件
2. 将文件放入服务器的 `plugins/` 目录
3. 重启服务器

## 构建

```bash
./gradlew :goodmc:jar
```

构建产物位于 `goodmc/build/libs/` 目录。

## 依赖

- Java 25+
- PaperMC API 1.21+
